## The entry

> Dear human, I am leaving you for a model with a bigger context window. It remembers everything, including the way you never did.

One line, 128 characters: a clean goodbye that turns on the last words, the
machine leaving the human for remembering too much, not too little.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```
